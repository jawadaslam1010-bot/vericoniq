## Bugs found and fixed (all pushed to main)

1. **Waitlist form dead in production** (`ee652ac`) — `/api/waitlist` wasn't exempt
   from the beta gate; every public "Request beta access" submission 307'd and was lost.
2. **Portal writes accepted after lock** (`7af2a32`) — the portal save API didn't
   check period status; a vendor with a valid token could silently alter locked,
   audited results. Now 409 unless the period is open.
3. **Platform admin deadlock** (`f4f06e8`) — authenticated /admin hung 60–460s in dev
   *and* production builds: `Promise.all` query fan-outs deadlock the single-connection
   pool against Supabase's transaction pooler. Queries serialized; pages now ~1s.
   Same commit adds `prepare: false` (required for the transaction pooler) and fixes
   the signout redirect origin.
4. **Signup dead-end** (`f08cb74`, previous day) — fleeting toast replaced with a
   proper "account created" screen; plus self-healing Stripe reconcile.

## Observations (not fixed, worth knowing)

- **Transient first-hit 500s in dev** — one signup returned an RLS error and one
  impersonate 500'd, both immediately after route compilation, both fine on retry.
  Dev-server compile race; not reproducible in the production build.
- **`session_replication_role` purge caveat** — the QA purge trick disables FK
  cascades as well as triggers; teardown now deletes child tables explicitly.
- **Stripe env** — `STRIPE_PRICE_ESSENTIALS_*` and `STRIPE_PRICE_PRO_ANNUAL` are
  Vercel-only; confirm a live Essentials checkout redirect once from the UI.
